# Jiazheng Zhu — Personal Homepage

Personal academic homepage of **Jiazheng Zhu** (朱家正), Ph.D. candidate in Astrophysics at the University of Science and Technology of China (USTC).

Research interests: **time-domain astrophysics, optical transients, and tidal disruption events (TDEs)**.

## Pages

- `index.html` — Home (hero, about, news, featured work)
- `publications.html` — Refereed publications
- `projects.html` — Research projects
- `cv.html` — Curriculum Vitae

## Deploy

This site is a static website and can be served directly via **GitHub Pages** (see the repo *Settings → Pages*), or opened locally by double-clicking `index.html`.
